A single-line museum label from the year 3000, placed beside an ordinary
object from today: a rubber duck. The label deadpans the year-3000
misreading — engineers confessed their errors to the bird daily, and the
bird that never answered was promoted to senior engineer.

## Run

```sh
node main.ts
```

This writes the label to `/output/entry.txt`.
